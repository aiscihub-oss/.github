# AISciHub OSS

**Open-source software. Built by young developers, across school boundaries.**

AISciHub OSS is a free, youth-led software community for people who want to
build useful things in the open. We bring together independent projects that
are understandable, usable, and ready for collaboration—not just collections
of code.

## How to get involved

- **Explore.** Read a project's README, try it, and find an open
  `good first issue` or another way to help.
- **Contribute.** Improve documentation, fix bugs, build features, review
  changes, and share technical feedback in the project's own repository.
- **Share a project.** If you maintain open-source software with a clear
  README and license, read the
  [submission process](https://github.com/aiscihub-oss/community/blob/main/CONTRIBUTING.md#submit-a-project).
  We are publishing the launch catalog first; submissions will open after
  the maintainers' review rules are in place.

## Our approach

- **Developer first.** Useful software, clear documentation, reproducible
  work, and respectful code review.
- **Independent ownership.** Join the catalog without transferring a
  repository or joining a particular school or organization.
- **Free and open.** No membership fees, competitions, certificates, or
  courses. Contribute at your own pace.
- **Privacy by design.** The community does not ask for young contributors'
  personal information. Work together through normal GitHub issues and
  pull requests, sharing project information rather than personal details.

Read our [project standards](https://github.com/aiscihub-oss/community/blob/main/PROJECT_ELIGIBILITY.md)
and [code of conduct](https://github.com/aiscihub-oss/community/blob/main/CODE_OF_CONDUCT.md).

**Build something useful. Make it understandable. Leave it better than you found it.**
